# Quiz Game in C

A simple console-based quiz game developed using C programming language.

## Features
- Multiple-choice questions
- Score calculation
- Interactive gameplay
- Console-based interface

## Technologies Used
- C Programming
- GCC Compiler

## How to Run

Compile:
gcc main.c -o quiz

Run:
./quiz

- Add timer
